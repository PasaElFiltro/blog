# PasaElFiltro — Open Research / Investigación Abierta

Research from **PasaElFiltro SpA** (Chile) on inter-instance behavioral variability in large language models.

**Principal Investigator:** Romina Pitronello — applied psychometrician (15+ years; national census-scale assessment, IRT/CTT/DIF, 350+ instruments) · ORCID [0009-0005-5159-6339](https://orcid.org/0009-0005-5159-6339)

## Preregistered study: inter-instance variability in LLM judges

- **Preregistration (OSF):** https://osf.io/zusb5
- **Materials, data & code (OSF):** https://osf.io/ue4qy
- **Manuscript:** submitted to *Behavior Research Methods*
- **Design:** 3×4×2 factorial, 480 fresh instances, 16-category battery
- **Core finding:** judgment-dependent categories showed ~2.7× the inter-instance divergence of procedural ones (aggregate ratio), persisting at temperature 0.

## Ethics line

Interactive chat conversations are never used as research data, examples, or quotations. Any prospective study with LLM instances preregisters its own protocol and includes a real, unpenalized option to decline or return null.
